# 928 GT REV-MATCH ASSIST

- [本番アプリ（車載メーター）を開く](https://ryota-hiura.github.io/revmatch/)
- [検証用シミュレーター（PC向け）を開く](https://ryota-hiura.github.io/revmatch/simulator.html)

OBD2非対応のネオクラシック・マニュアルトランスミッション車（初期ターゲット：**1991年式 Porsche 928 GT / 5速MT / 5.0L V8**）向けに開発した、車両無加工・スマートフォン完結型の回転数検出・レブマッチ支援Webアプリケーションです。

マイク入力（エンジン音のFFT解析）とGPSを使って現在のギアポジションを推定し、シフトダウン時（1段・2段落とし）の目標ブリッピング回転数を928 GT風の速度計・タコメーターに表示します。

## 3. コアアルゴリズム仕様（`index.html`）

### 3.1 音響FFTによるエンジン回転数（RPM）検出

* `AnalyserNode`（`fftSize = 8192`）を使用し、ノイズ抑制（`noiseSuppression`）やAGCを無効化した生音声から周波数スペクトルを取得。
* **爆発周波数とRPMの換算式（4ストロークエンジン）:**

$$\text{RPM} = f_{\text{primary}} \times \frac{120}{\text{気筒数}}$$


* 8気筒（928 GT）の場合：1回転あたり4回爆発するため $\text{RPM} = f_{\text{primary}} \times 15$


* **精度向上ロジック:**
* 前フレームのRPM（`smoothedRpm`）の $\pm 25\%$ 以内のピークを優先評価し、倍音（2次・0.5次）へのオクターブ飛びを防止。
* ピークビンとその前後ビンを用いた放物線補間（Parabolic Interpolation）によりサブビン精度の周波数を算出。



### 3.2 ギアポジション推定と目標回転数計算

MT車はクラッチ接続中、車速 $V$ と回転数 $N$ の比率 $R = N / V$ がギアごとに一定であることを利用する。

1. **ギア判定:** 実測比率 $R_{\text{now}}$ と車種プロファイル（`PROFILES`）に定義された各ギアの基準比率 $R_i$ を比較し、誤差 $6.5\%$ 以内の状態が一定フレーム継続した場合に `engagedGear`（噛み合い中）と確定する。
2. **直前ギアの保持（`referenceGear`）:** 比率が基準から外れた場合は「クラッチ切断／ニュートラル（`isClutchOpen = true`）」と判定するが、直前まで入っていたギア番号を `referenceGear` に保持し続ける。
3. **ターゲットRPM算出:**
* 1段落とし目標： $N_{\text{target1}} = V_{\text{now}} \times R_{\text{referenceGear} - 1}$
* 2段落とし目標： $N_{\text{target2}} = V_{\text{now}} \times R_{\text{referenceGear} - 2}$
* 目標値が `redline` を超える場合はオーバーレブ警告を表示する。
* タコメーター上に1段・2段シフトダウンの目標RPMを目盛り位置で表示する。レブリミットを超える目標は赤色で警告する。
* クラッチ切断中に実回転数が1段落とし目標の $\pm 120\text{ rpm}$ に入ると針を緑色にし、ビープ音を鳴らす。

### 3.3 休止中のジャーク計測

ジャーク計測とシフト採点のロジックは `jerk-telemetry.js` に保管しています。現行アプリでは読み込まず、加速度センサーの計測・ログ出力・AI分析機能は動作しません。

## 4. 車種プロファイルデータ構造（`PROFILES`）

新車種を追加する場合は `index.html` 内の `PROFILES` オブジェクトに以下の形式で追加する。

```javascript
"car_id": {
  name: "表示名",
  cylinders: 8,         // 気筒数（4ストローク前提）
  redline: 6800,        // レブリミット (rpm)
  // 1速〜トップギアまでの [エンジン回転数(rpm) / 車速(km/h)] 比率配列
  gearRatios: [87.07, 58.20, 42.26, 31.87, 23.09]
}

```
