# REV-MATCH ASSIST & JERK TELEMETRY

- [本番アプリ（車載メーター）を開く](https://ryota-hiura.github.io/revmatch/)
- [検証用シミュレーター（PC向け）を開く](https://ryota-hiura.github.io/revmatch/simulator.html)

OBD2非対応のネオクラシック・マニュアルトランスミッション車（初期ターゲット：**1991年式 Porsche 928 GT / 5速MT / 5.0L V8**）向けに開発した、車両無加工・スマートフォン完結型のドライビング支援＆テレメトリWebアプリケーションです。

マイク入力（エンジン音のFFT解析）、GPS、加速度センサー（IMU）を組み合わせ、現在のギアポジション推定、シフトダウン時（1段・2段落とし）の目標ブリッピング回転数のリアルタイム提示、およびシフトショック（躍度：Jerk）の計測・AI分析用ログ出力を行います。

## 3. コアアルゴリズム仕様（`index.html`）

### 3.1 音響FFTによるエンジン回転数（RPM）検出

* `AnalyserNode`（`fftSize = 16384`）を使用し、ノイズ抑制（`noiseSuppression`）やAGCを無効化した生音声から周波数スペクトルを取得。
* **基底周波数とRPMの換算式:** FFTで推定したエンジン回転の基底周波数を使う。

$$\text{RPM} = f_{\text{base}} \times 60$$


* 8気筒（928 GT）の爆発周波数は基底周波数の4倍。爆発音が強い場合も、倍音列を評価して基底周波数を推定する。


* **精度向上ロジック:**
* スペクトルのピークを抽出し、1〜8次高調波との整合性から基底周波数候補を採点する。基音ピーク、気筒数から求めた爆発次数のピーク、前フレームからの連続性も評価する。
* ピークビンとその前後ビンを用いた放物線補間（Parabolic Interpolation）により周波数を算出する。



### 3.2 ギアポジション推定と目標回転数計算

MT車はクラッチ接続中、車速 $V$ と回転数 $N$ の比率 $R = N / V$ がギアごとに一定であることを利用する。

1. **ギア判定:** 実測比率 $R_{\text{now}}$ と車種プロファイル（`PROFILES`）に定義された各ギアの基準比率 $R_i$ を比較し、誤差 $6.5\%$ 以内の状態が一定フレーム継続した場合に `engagedGear`（噛み合い中）と確定する。
2. **直前ギアの保持（`referenceGear`）:** 比率が基準から外れた場合は「クラッチ切断／ニュートラル（`isClutchOpen = true`）」と判定するが、直前まで入っていたギア番号を `referenceGear` に保持し続ける。
3. **ターゲットRPM算出:**
* 1段落とし目標： $N_{\text{target1}} = V_{\text{now}} \times R_{\text{referenceGear} - 1}$
* 2段落とし目標： $N_{\text{target2}} = V_{\text{now}} \times R_{\text{referenceGear} - 2}$
* 目標値が `redline` を超える場合はオーバーレブ警告を表示する。
* クラッチ切断中に実回転数が $N_{\text{target1}} \pm 120\text{ rpm}$ に入るとゲージを緑色に点灯し、ビープ音を鳴らす。



### 3.3 ジャーク（躍度）計測とシフト採点

* 加速度センサー（`devicemotion` の重力除去済み前後加速度 $a$）の時間微分から躍度（$\text{Jerk} = |\Delta a / \Delta t|$ [$\text{m/s}^3$]）を算出。
* クラッチ切断状態から低いギアへの再接続（`matchedGear < referenceGear`）を検知した瞬間、クラッチ切断中の最大回転数（`peakRpmDuringClutch`）と理想回転数の誤差（`rpmError`）、および直近600ms以内の最大躍度（`maxJerkMs3`）を記録し、100点満点でスコアリングする。

## 4. 車種プロファイルデータ構造（`PROFILES`）

新車種を追加する場合は `index.html` 内の `PROFILES` オブジェクトに以下の形式で追加する。

```javascript
"car_id": {
  name: "表示名",
  cylinders: 8,         // 気筒数（4ストローク前提）
  redline: 6800,        // レブリミット (rpm)
  // 1速〜トップギアまでの [エンジン回転数(rpm) / 車速(km/h)] 比率配列
  gearRatios: [87.07, 58.20, 42.26, 31.87, 23.09]
}

```
